Zwecke und Rechtsgrundlage

Für den technischen Betrieb dieser Website nutze ich GitHub Pages, ein Angebot der GitHub, Inc. (Teil von Microsoft). Mein berechtigtes Interesse hierzu liegt in der sicheren, weltweit zugänglichen und kosteneffizienten Bereitstellung dieser Website. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO.

Verarbeitung durch GitHub

Beim Aufruf der Website verarbeitet GitHub in eigener Verantwortlichkeit technisch notwendige Daten (z. B. IP-Adresse, Browser-Informationen, Zeitstempel), um die Website bereitzustellen, die IT-Sicherheit zu gewährleisten und Missbrauch abzuwehren. Rechtsgrundlage hierfür ist Art. 6 Abs. 1 lit. f DSGVO.

Weiterführende Angaben zu den verarbeiteten Daten, zu Speicherdauer, Empfängern und zu internationalen Datenübermittlungen finden Sie im GitHub Privacy Statement (nur auf Englisch verfügbar).
